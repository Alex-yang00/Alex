FAQ.

Only the rules needed to submit correctly.

What counts as a valid submission?

Publish a public X post about a Hy3 project, tag @TencentHunyuan and @novita_labs, include #Hy3Novita, add at least one proof item such as a screenshot, video, live demo, GitHub repo, or project page, then submit the X post link in Discord.

What can I build with Hy3?

Web demos, games, agents, MCP tooling, automations, workflows, API demos, and other public projects are all welcome if Hy3 meaningfully contributes to the result.

How are likes and views counted?

Most Liked and Most Viewed use the likes and views on the X post link submitted in Discord, measured at the challenge cutoff.

Can one project win multiple rewards?

A project can receive at most one performance prize. If the same submitted X post ranks first for both Most Liked and Most Viewed, it wins Most Liked; Most Viewed goes to the next eligible submission by views. Lucky Draw can be won at most once per project or author.

Will submissions be reviewed?

We reserve the right to manually review submissions, especially Hy3 usage notes, proof materials, project accessibility, and obvious signs of fake engagement or non-genuine work.

When does the challenge end?

The challenge ends July 21, 2026 at 8:59:59 AM PT. Submissions must be posted on X and submitted in Discord before the deadline.
