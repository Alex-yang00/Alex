FAQ

Common questions

Is there a detailed breakdown of the credits?

Eligible startups can receive up to $10,000 in credits across Novita AI's Model APIs and Agent Sandbox. The program provides up to $1,000 in credits upfront. The next $5,000 is matched at a 1:1 ratio, every dollar spent earns one dollar in credit. For the final $4,000, every two dollars spent earns one dollar in credit. These credits can be redeemed for one year.

What products are covered?

Credits are split across Novita AI's startup products: up to $5,000 for Agent Sandbox usage and up to $5,000 for Model API usage.

How are credits approved?

Novita reviews stage, team, current spend, backing, traction, and expected Model API or Agent Sandbox usage.
